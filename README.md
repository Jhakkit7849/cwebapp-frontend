# C WebApp - Frontend (React + Vite)

ระบบแพลตฟอร์มการเรียนรู้และฝึกฝนการเขียนโปรแกรมด้วย **ภาษา C (C Programming Learning Platform)** ในรูปแบบ Secure Web Application ที่พัฒนาขึ้นเพื่อช่วยให้ผู้เรียนสามารถศึกษาบทเรียน ทำแบบทดสอบ (Quiz) และฝึกทำโจทย์คอมไพล์โค้ดจริงผ่านหน้าเว็บไซต์ได้ครบวงจร

## ✨ คุณสมบัติของระบบ (Features)
* **Lessons & Learning:** ระบบคลังบทเรียนภาษา C แบ่งตามหมวดหมู่ พร้อมตัวกรองค้นหาบทเรียน
* **Coding Challenges:** โจทย์ท้าทายการเขียนโค้ดภาษา C ระบบตรวจผลลัพธ์การรันโค้ดและตรวจเช็กความถูกต้องแบบอัตโนมัติ
* **Community Forums:** ระบบบอร์ดชุมชนสำหรับสอบถาม พูดคุย และแลกเปลี่ยนความรู้ระหว่างผู้ใช้งาน
* **Leaderboard / Ranking:** ตารางคะแนนรวมและอันดับของผู้ใช้งานในระบบเพื่อเพิ่มความท้าทายในการเรียนรู้
* **Secure Authentication:** ระบบสมาชิกและการยืนยันตัวตนความปลอดภัยสูง ป้องกันข้อมูลผู้ใช้ตามมาตรฐานหลัก

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
* **Frontend Core:** React 18, Vite
* **Styling & UI:** Tailwind CSS / Custom CSS Components
* **Routing:** React Router DOM (configured with sub-path routing)
* **State & Fetching:** Axios / Fetch API
* **Backend API Connecting:** Node.js / Express Deployment ([cwebapp-backend](https://cwebapp-backend.onrender.com))
* **Database & Storage:** Supabase Cloud Storage
